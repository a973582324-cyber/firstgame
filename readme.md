# 我的第一个游戏，基于unity引擎创作

## 游戏玩法
1. 玩家只需要按空格即可实现让小鸟向上跳跃，如果碰到地图边界或者碰到迎面而来的柱子，会导致小鸟死亡。
2. 存在难度递增机制，随着时间增加难度会递增，提高游戏的挑战性。
3. 存在最高分机制，每次穿过管子都会增加一分。

## 游戏脚本机制
1. bird脚本：

    实现小鸟的碰撞逻辑，使用vector2加物理速度实现小鸟的跳跃。
2. backgroundco:
    实现背景的运动。
3. logicmanager:
    实现整个游戏的逻辑方法，包括ui界面的控制，游戏的运行状态，分数的增加。
4. pipemiddle:
    碰撞箱脚本，检测小鸟是否越过管道。
5. pipemove:
    管道的运动。
6. pipespawn:
    管道生成器，在该位置生成管道并让管道运动，随着时间移动，管道生成速度加快，有一个时间最小阈值。

## 游戏经验
- 学习了怎么在脚本里控制物体的运动：用向量实现。
- 学习了怎么实现物体的碰撞检测。
- 学到了ui制作的技巧，使用父类控制ui的显示。
- 学到了怎么实现物体的旋转。
- 学习了生成器的应用。
- 了解了很多没有接触过的新类。
- 使用了很多新的方法查找场景中的物体。
## 游戏制作总结：
- 这次不是ai帮忙生成的游戏，是根据油管上的教程一步一步实现的基本逻辑，之后自己添加了背景运动，最大积分机制，难度递增机制。总的来说制作游戏的时间很快乐。
